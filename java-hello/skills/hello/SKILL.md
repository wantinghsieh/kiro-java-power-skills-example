# Java Hello World

1. Create `Main.java`:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

2. Compile it with `javac Main.java`.
3. Run it with `java Main`. It should print `Hello, World!`.
